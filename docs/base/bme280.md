# BME280 Driver

**Files:** `lib/bme280/bme280.hpp`, `lib/bme280/bme280.cpp`

The BME280 is a Bosch sensor that measures temperature, barometric pressure, and relative humidity over I2C. This driver implements the sensor entirely from scratch using direct I2C register access and the official Bosch compensation formulas.

---

## API

### `bool BME280::init()`

Initialises the sensor. Must be called once in `setup()` before any `read()` calls.

1. Reads the chip ID register (`0xD0`) and verifies it equals `0x60`. Returns `false` if the chip is not found.
2. Loads all 32 factory calibration coefficients from the sensor's NVM.
3. Configures the sensor:
   - Humidity oversampling ×1 (`CTRL_HUM = 0x01`)
   - Sleep mode (`CTRL_MEAS = 0x00`) — each `read()` call triggers a fresh forced measurement on demand

Returns `true` on success.

```cpp
if (!bme.init()) {
    // sensor not found or wiring issue
}
```

---

### `bool BME280::read(float& temp, float& press, float& hum)`

Triggers a forced measurement, waits for it to complete, then burst-reads 8 bytes starting at register `0xF7` (press_msb through hum_lsb).

Sequence inside `read()`:
1. Write `CTRL_MEAS = 0x25` — starts a one-shot forced measurement (temp + press oversampling ×1).
2. Poll `REG_STATUS` bit 3 (measuring flag) until it clears, with a 100 ms timeout.
3. Burst-read 8 bytes and apply the compensation formulas.

| Parameter | Type | Unit | Description |
|-----------|------|------|-------------|
| `temp` | `float&` | °C | Compensated temperature |
| `press` | `float&` | hPa | Compensated pressure |
| `hum` | `float&` | %RH | Compensated relative humidity |

Returns `true` on success; `false` if the I2C read returned fewer than 8 bytes or the measurement timed out.

```cpp
float temp, press, hum;
if (bme.read(temp, press, hum)) {
    Serial.printf("T: %.2f C  P: %.2f hPa  H: %.2f%%\n", temp, press, hum);
}
```

## Register map

| Register | Address | Description |
|----------|---------|-------------|
| `REG_CHIPID` | `0xD0` | Chip identification — should read `0x60` |
| `REG_CTRL_HUM` | `0xF2` | Humidity oversampling control |
| `REG_STATUS` | `0xF3` | Bit 3 = measuring flag; cleared when conversion is done |
| `REG_CTRL_MEAS` | `0xF4` | Temp/press oversampling + mode (`0x00` = sleep, `0x25` = forced) |
| `REG_PRESS_MSB` | `0xF7` | Start of burst-read data block |
| `REG_DIG_T1` | `0x88` | Start of temperature calibration block |
| `REG_DIG_H1` | `0xA1` | H1 humidity calibration byte |
| `REG_DIG_H2` | `0xE1` | Start of H2–H6 humidity calibration block |

---

## Calibration and compensation

The BME280 stores 32 factory-trimmed calibration coefficients in NVM. They are read once during `init()` via `_readCalibration()` and stored as private member variables (`_dig_T1` … `_dig_H6`).

The three compensation functions (`_compensateTemp`, `_compensatePressure`, `_compensateHumidity`) implement the integer fixed-point formulas from the BME280 datasheet (section 8.2). Temperature must always be compensated first because it calculates `_t_fine`, an intermediate value that pressure and humidity compensation depend on.

The raw data layout in the 8-byte burst read:

| Byte | Content |
|------|---------|
| 0 | press_msb |
| 1 | press_lsb |
| 2 | press_xlsb [7:4] |
| 3 | temp_msb |
| 4 | temp_lsb |
| 5 | temp_xlsb [7:4] |
| 6 | hum_msb |
| 7 | hum_lsb |

Temperature and pressure are 20-bit values; humidity is 16-bit.
