# BMP580 Driver

**Files:** `../../cansat-edu-lib/bmp580/bmp580.hpp`, `../../cansat-edu-lib/bmp580/bmp580.cpp` (consumed by `base/` via `lib_extra_dirs`)

The BMP580 is a Bosch sensor that measures barometric pressure and temperature over
I2C. This driver implements the sensor entirely from scratch using direct I2C register
access. Humidity is measured by a separate chip — see [aht20.md](aht20.md).

---

## API

### `bool BMP580::init()`

Initialises the sensor. Must be called once in `setup()` before any `read()` calls.

1. Reads the chip ID register (`0x01`) and verifies it equals `0x50` or `0x51`. Returns `false` if the chip is not found.
2. Puts the sensor in standby mode.
3. Configures oversampling: pressure enabled, 4× pressure OSR, 2× temperature OSR (`0x36`).
4. Leaves the sensor in standby — each `read()` call triggers a fresh forced measurement on demand.

Returns `true` on success.

```cpp
if (!bmp580.init()) {
    // sensor not found or wiring issue
}
```

---

### `bool BMP580::read(float& temp, float& press)`

Triggers a forced measurement, waits 12 ms for it to complete, then burst-reads 6 bytes
starting at register `0x1D` (temperature XLSB through pressure MSB).

| Parameter | Type | Unit | Description |
|-----------|------|------|-------------|
| `temp` | `float&` | °C | Temperature |
| `press` | `float&` | hPa | Pressure |

Returns `true` on success; `false` if the sensor wasn't detected during `init()`.

```cpp
float temp, press;
if (bmp580.read(temp, press)) {
    Serial.printf("T: %.2f C  P: %.2f hPa\n", temp, press);
}
```

---

## Register map

| Register | Address | Description |
|----------|---------|-------------|
| `REG_CHIP_ID` | `0x01` | Chip identification — `0x50` or `0x51` |
| `REG_TEMP_XLSB` | `0x1D` | Start of 6-byte burst-read data block (temp then pressure) |
| `REG_OSR_CONFIG` | `0x36` | Oversampling configuration |
| `REG_ODR_CONFIG` | `0x37` | Output data rate + power mode |

---

## Conversion

Both temperature and pressure are 24-bit raw values, converted with fixed-point
division (no Bosch trim/compensation table needed — the BMP580 outputs
already-linearised values):

```cpp
temp  = (float)rawTemp / 65536.0f;          // °C
press = (float)rawPress / 64.0f / 100.0f;   // Pa -> hPa
```

The 6-byte burst read layout starting at `0x1D`:

| Bytes | Content |
|-------|---------|
| 0–2 | Temperature (24-bit, signed) |
| 3–5 | Pressure (24-bit, unsigned) |
