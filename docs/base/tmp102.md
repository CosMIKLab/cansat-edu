# TMP102 Driver

**Files:** `../../cansat-edu-lib/tmp102/tmp102.hpp`, `../../cansat-edu-lib/tmp102/tmp102.cpp` (consumed by `base/` via `lib_extra_dirs`)

The TMP102 is a simple I2C temperature sensor used as a secondary/backup temperature
reading alongside the BMP580 and AHT20.

---

## API

### `bool TMP102::init()`

Probes the device by attempting an I2C transaction to its address. Returns `true` if
the device acknowledges.

```cpp
if (!tmp102.init()) {
    // sensor not found or wiring issue
}
```

---

### `bool TMP102::read(float& temp)`

Reads 2 bytes from register `0x00` and converts the 12-bit signed value.

| Parameter | Type | Unit | Description |
|-----------|------|------|-------------|
| `temp` | `float&` | °C | Temperature |

Returns `true` on success; `false` if the device wasn't detected during `init()` or the
I2C read failed.

```cpp
float temp;
if (tmp102.read(temp)) {
    Serial.printf("T2: %.2f C\n", temp);
}
```

---

## Conversion

```cpp
int16_t value = (msb << 4) | (lsb >> 4);  // 12-bit
if (value & 0x0800) value |= 0xF000;      // sign-extend
temp = value * 0.0625f;                   // °C, 0.0625 °C/LSB
```

---

## Global instance

```cpp
extern TMP102 tmp102;  // defined in tmp102.cpp
```

Include `tmp102.hpp` to use `tmp102` from any translation unit.
